# HRAP: Computer Science Education & Gamification Research

Supporting **Dr. Jie Cao** in research dedicated to improving the effectiveness of computer science education by investigating the impacts of gamification and customizing interactive Jupyter Notebook environments using Python.

---

## 🔬 Research Overview

This repository hosts interactive learning materials, experimental modules, and curriculum tools developed to support research in computer science education pedagogy. The primary focus areas include:

- **🎮 Gamification in CS Education**: Analyzing and applying gamified learning mechanics (progressive scenario-based tasks, immediate feedback loops, and interactive checkpoints) to boost student engagement, persistence, and conceptual understanding.
- **📓 Customizing Jupyter Notebooks**: Engineering guided, interactive Python notebook environments tailored for computer science learners, featuring structured exercise workflows, automated assertions, and scaffolded hints.
- **📊 Practical Computing & Data Literacy**: Designing intuitive exercises on foundational data structures, multidimensional array manipulation (NumPy), and data-driven problem solving.

```text
HRAP/

├── .gitignore         # Standard ignore rules for checkpoints and environment files
└── README.md          # Research project documentation and setup guide
```

### Featured Modules

* **`Arrays.ipynb`**: A scenario-based exercise exploring 2D array mechanics through a real-world multi-day festival temperature dataset. Covers:
  1. Creating 2D NumPy arrays from nested data structures.
  2. Inspecting matrix properties (`shape`, `ndim`, `dtype`).
  3. Boolean indexing and conditional filtering.
  4. Matrix slicing and boundary indexing.

## 🚀 Getting Started

### Prerequisites

Ensure you have Python 3.10+ installed on your system.

### Installation

Clone the repository and install the necessary dependencies:

```bash
git clone https://github.com/niimme/HRAP.git
cd HRAP
pip install numpy jupyterlab
```

### Launching the Notebooks

Start JupyterLab or Jupyter Notebook in your browser:

```bash
jupyter lab
```
or
```bash
jupyter notebook
```

Open `Arrays.ipynb` to run the interactive exercise cells.
